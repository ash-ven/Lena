# CasellaConsenso

Casella da spuntare per il consenso privacy alla registrazione, con link all'informativa.

- **Cosa fornisce chi lo usa**: il testo del consenso, il link all'informativa nella sua versione corrente, lo stato (spuntata o no).
- Mai già spuntata: la persona la spunta a mano. Senza spunta il pulsante «Crea accesso» spiega cosa manca invece di essere disattivato.
- Casella 20 px con contorno 2 px `bordo-campo`, angoli `raggio-casella`; area da toccare almeno 44 px.
- Spuntata: fondo `brace`, segno di spunta `su-brace`.
- Testo in `corpo-piccolo` colore `testo`; link all'informativa in `testo-brace`, sottolineato.
- Va salvata con la data e la versione dell'informativa accettata.
