# Pulsante

Il pulsante principale di Lena: fondo `brace`, scritta `su-brace`, uno solo per vista.

- **Cosa fornisce chi lo usa**: il testo (un verbo, una o due parole, senza punto) e l'azione.
- Fondo `brace`, scritta `su-brace` in stile `pulsante`, angoli `raggio-controllo`, altezza almeno 44 px, interno `spazio-3`.
- Sul telefono occupa tutta la larghezza del modulo.
- Attivo da tastiera: anello `anello-attivo` di 2 px staccato di 2 px.
- In attesa (per esempio mentre accede): resta arancio, il testo diventa «Accesso…» e non si ripete l'invio.
- Non usare due pulsanti `brace` nella stessa vista; le azioni secondarie non hanno ancora uno stile proprio.
- Mai scritta bianca sull'arancio.
